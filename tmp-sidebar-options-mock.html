How to read these
  • A — control / closest to shipping UI.
  • B — if folder + watch should feel like the session object.
  • C — if short window heights / tiling are common (you already densify below 700px).
  • D — if queue progress should dominate; modes become secondary.
  • E — if mode is “set once”, free vertical space for entry clarity.
  • F — strongest visual grouping without changing interaction model.
  • G — more tool-palette / creative-app vernacular.
  • H — onboarding-friendly pipeline; Process moves to the top.

All options keep the locked product chrome: Select image + Open folder, optional Watch (folder only), Quality modes with NC badges, sticky Process with queue counts.
