# Queue icons

SVGs from **Lucide** ([lucide-static](https://github.com/lucide-icons/lucide) v0.469.0), ISC license.

Vendored as static assets (not an npm dependency). Used only by the collapsible queue drawer row actions / status marks.

| File | Lucide name | Role |
|------|-------------|------|
| `rotate-ccw.svg` | `rotate-ccw` | Retry failed item |
| `external-link.svg` | `external-link` | Reveal output in folder |
| `x.svg` | `x` | Remove item from queue |
| `check.svg` | `check` | Done status mark |
| `alert.svg` | `triangle-alert` | Failed status mark |
